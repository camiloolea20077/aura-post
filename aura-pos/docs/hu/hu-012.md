# HU-012: Abonos a Cuentas por Pagar

## Descripción
Permite registrar abonos (pagos) a cuentas por pagar. Un abono representa una salida de caja que reduce el saldo pendiente de una cuenta por pagar a un proveedor.

## Criterios de Aceptación

### Registrar Abono a Cuenta por Pagar
- [ ] Endpoint: `POST /api/cuentas-pagar/{id}/abonos`
- [ ] Request: `AbonoPagarDto`
  - `monto` (BigDecimal, requerido): monto del abono
  - `metodoPago` (String, requerido): método de pago (EFECTIVO, TRANSFERENCIA, TARJETA, CHEQUE, OTRO)
  - `referencia` (String, opcional): número de referencia del pago
  - `banco` (String, opcional): banco emisor si aplica
  - `fechaPago` (LocalDateTime, opcional): fecha del pago (default: ahora)
- [ ] Validaciones:
  - La cuenta por pagar debe existir y pertenecer a la empresa
  - El monto debe ser mayor a 0
  - El monto no puede ser mayor al saldo pendiente
  - La cuenta no debe estar en estado 'pagada'
- [ ] Response: `ApiResponse<AbonoPagarDto>` con status 201
- [ ] Transaccional: registra el abono y actualiza el saldo de la cuenta

### Actualizar saldo de cuenta automáticamente
- [ ] Después de registrar un abono:
  - Se incrementa `total_abonado` en el monto del abono
  - Se decrementa `saldo_pendiente` en el monto del abono
  - Si `saldo_pendiente` <= 0, el estado cambia a 'pagada'
- [ ] El abono se registra con el usuario_id del JWT

### Listar Abonos de una Cuenta
- [ ] Endpoint: `GET /api/cuentas-pagar/{id}/abonos`
- [ ] Response: `ApiResponse<List<AbonoPagarDto>>`
- [ ] Incluye: id, monto, metodoPago, referencia, banco, fechaPago, usuarioNombre, createdAt
- [ ] Orden: fecha_pago DESC

### Obtener Abono por ID
- [ ] Endpoint: `GET /api/cuentas-pagar/{cuentaId}/abonos/{abonoId}`
- [ ] Response: `ApiResponse<AbonoPagarDto>`

### Eliminar Abono (Anulación)
- [ ] Endpoint: `DELETE /api/cuentas-pagar/{cuentaId}/abonos/{abonoId}`
- [ ] Solo permite anulación si el abono es del día actual
- [ ] Validaciones:
  - No permite si la cuenta ya está marcada como pagada
  - No permite si al eliminar el abono el saldo queda negativo
- [ ] Transaccional: reversa el abono y recalcula saldo
- [ ] Response: `ApiResponse<Void>` con status 200

## Seguridad
- [ ] Requiere JWT válido
- [ ] Filtra por empresa_id del token
- [ ] Roles permitidos: ADMIN, CONTADOR, COMPRAS

## Cálculos Automáticos
```
total_abonado = total_abonado + monto_abono
saldo_pendiente = saldo_pendiente - monto_abono

IF saldo_pendiente <= 0 THEN
    estado = 'pagada'
    saldo_pendiente = 0
END IF
```
