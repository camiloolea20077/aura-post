# HU-013: Cálculo de Totales de Cuentas por Cobrar y Pagar

## Descripción
Proporciona endpoints para obtener los cálculos agregados de totales de deuda, total abonado y saldo pendiente para cuentas por cobrar y por pagar. Estos cálculos se utilizan para dashboards y reportes financieros.

## Criterios de Aceptación

### Obtener Resumen de Cuentas por Cobrar
- [ ] Endpoint: `GET /api/cuentas-cobrar/resumen`
- [ ] Request Query Params (todos opcionales):
  - `fechaDesde`: fecha inicial de filtro
  - `fechaHasta`: fecha final de filtro
  - `clienteId`: filtrar por cliente específico
  - `estado`: filtrar por estado (activa, pagada, vencida)
- [ ] Response: `ApiResponse<CuentaCobrarResumenDto>`
- [ ] Campos del resumen:
  - `totalCuentas`: cantidad de cuentas que cumplen el filtro
  - `totalDeuda`: suma de todos los total_deuda
  - `totalAbonado`: suma de todos los total_abonado
  - `saldoPendiente`: suma de todos los saldo_pendiente (totalDeuda - totalAbonado)
  - `cantidadActivas`: cuentas con estado 'activa'
  - `cantidadPagadas`: cuentas con estado 'pagada'
  - `cantidadVencidas`: cuentas con estado 'vencida'
- [ ] Query SQL con suma agregada:
```sql
SELECT 
    COUNT(*) AS total_cuentas,
    SUM(total_deuda) AS total_deuda,
    SUM(total_abonado) AS total_abonado,
    SUM(saldo_pendiente) AS saldo_pendiente,
    COUNT(*) FILTER (WHERE estado = 'activa') AS cantidad_activas,
    COUNT(*) FILTER (WHERE estado = 'pagada') AS cantidad_pagadas,
    COUNT(*) FILTER (WHERE estado = 'vencida') AS cantidad_vencidas
FROM cuentas_cobrar
WHERE empresa_id = :empresaId
  AND deleted_at IS NULL
  -- filtros adicionales
```

### Obtener Resumen de Cuentas por Pagar
- [ ] Endpoint: `GET /api/cuentas-pagar/resumen`
- [ ] Request Query Params (todos opcionales):
  - `fechaDesde`: fecha inicial de filtro
  - `fechaHasta`: fecha final de filtro
  - `proveedorId`: filtrar por proveedor específico
  - `estado`: filtrar por estado (activa, pagada, vencida)
- [ ] Response: `ApiResponse<CuentaPagarResumenDto>`
- [ ] Misma estructura que cuentas por cobrar

### Obtener Totales por Cliente (Cuentas por Cobrar)
- [ ] Endpoint: `GET /api/cuentas-cobrar/resumen/cliente/{clienteId}`
- [ ] Response: `ApiResponse<ClienteCuentaResumenDto>`
- [ ] Campos:
  - `clienteId`, `clienteNombre`, `numeroCuentas`
  - `totalDeuda`, `totalAbonado`, `saldoPendiente`

### Obtener Totales por Proveedor (Cuentas por Pagar)
- [ ] Endpoint: `GET /api/cuentas-pagar/resumen/proveedor/{proveedorId}`
- [ ] Response: `ApiResponse<ProveedorCuentaResumenDto>`
- [ ] Campos:
  - `proveedorId`, `proveedorNombre`, `numeroCuentas`
  - `totalDeuda`, `totalAbonado`, `saldoPendiente`

### Obtener Cuentas Vencidas
- [ ] Endpoint: `GET /api/cuentas-cobrar/vencidas`
- [ ] Filtra cuentas donde fecha_vencimiento < now() AND estado = 'activa'
- [ ] Response: `ApiResponse<List<CuentaCobrarTableDto>>`

- [ ] Endpoint: `GET /api/cuentas-pagar/vencidas`
- [ ] Filtra cuentas donde fecha_vencimiento < now() AND estado = 'activa'
- [ ] Response: `ApiResponse<List<CuentaPagarTableDto>>`

## Seguridad
- [ ] Requiere JWT válido
- [ ] Filtra por empresa_id del token
- [ ] Roles permitidos: ADMIN, CONTADOR, GERENTE

## Notas Técnicas
- Los cálculos se realizan directamente en la base de datos (SUM) para mejor rendimiento
- El campo saldo_pendiente se calcula como: total_deuda - total_abonado
- Las cuentas con deleted_at no se incluyen en los cálculos
- El endpoint de vencidas recalcula el estado si ya pasó la fecha de vencimiento
