# HU-F035: Permisos de Módulos por Empresa - Frontend

**Epic:** EP-006 - Sistema de Permisos de Módulos (Frontend)

## Descripción

Como super-admin de la plataforma, quiero una interfaz para activar/desactivar módulos y submódulos específicos para cada empresa.

## Modelos TypeScript

```typescript
// permiso.model.ts
export interface ModuloPermiso {
  id: number;
  codigo: string;
  nombre: string;
  activo: boolean;
  submodulos: SubmoduloPermiso[];
}

export interface SubmoduloPermiso {
  id: number;
  codigo: string;
  nombre: string;
  activo: boolean;
}

export interface EmpresaPermisos {
  empresa_id: number;
  nit: string;
  razon_social: string;
  modulos: ModuloPermiso[];
}

export interface UpdatePermisoDto {
  modulos: ModuloPermisoUpdate[];
}

export interface ModuloPermisoUpdate {
  modulo_id: number;
  activo: boolean;
  submodulos?: SubmoduloPermisoUpdate[];
}

export interface SubmoduloPermisoUpdate {
  submodulo_id: number;
  activo: boolean;
}
```

## Servicio

```typescript
// permiso.service.ts
@Injectable({ providedIn: 'root' })
export class PermisoService {
  private readonly baseUrl = `${environment.apiUrl}platform/empresas`;

  constructor(private readonly http: HttpClient) {}

  getPermisos(empresaId: number): Observable<EmpresaPermisos> {
    return this.http.get<EmpresaPermisos>(`${this.baseUrl}/${empresaId}/permisos`);
  }

  updatePermisos(empresaId: number, dto: UpdatePermisoDto): Observable<void> {
    return this.http.put<void>(`${this.baseUrl}/${empresaId}/permisos`, dto);
  }
}
```

## UI/UX

### Panel de Permisos (index-permisos)

**Estructura:**
- Selector de empresa (Dropdown) - carga lista de empresas
- Acordeón de módulos
  - Cada módulo tiene un toggle switch para activar/desactivar
  - Lista de submódulos con checkboxes individuales
  - Si el módulo está desactivado, los submódulos aparecen deshabilitados

**Comportamiento:**
- Al desactivar un módulo: automáticamente se desmarcan todos sus submódulos
- Al activar un módulo: los submódulos mantienen su estado anterior
- Un submódulo solo puede activarse si su módulo padre está activo
- Botón "Guardar Cambios" (solo se habilita si hay cambios)

## API Reference

| Método | Endpoint | Descripción |
|--------|----------|-------------|
| GET | `/api/platform/empresas/{id}/permisos` | Obtener permisos |
| PUT | `/api/platform/empresas/{id}/permisos` | Actualizar permisos |

## Casos de Uso

1. **Seleccionar empresa**: Elegir empresa del dropdown
2. **Ver permisos actuales**: Cargar panel con módulos/submódulos y estados
3. **Activar módulo**: Toggle switch → se habilitan todos los submódulos
4. **Desactivar módulo**: Toggle switch → se desmarcan todos los submódulos
5. **Activar submódulo individual**: Checkbox → solo si el módulo padre está activo
6. **Guardar cambios**: Click en guardar → PUT al API → feedback de éxito/error
